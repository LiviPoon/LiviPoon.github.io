# Native site

This directory owns the standalone HTML pages outside Art and Thoughts. The standalone homepage
remains in `portfolio-src/`; `/art/`, `/blog/`, and Thoughts tag pages remain generated by Quartz.

The hybrid build runs Quartz first and then copies this directory over `public/`. Edit these HTML
files directly when changing non-Thoughts pages. Shared media continues to come from `content/`, so
existing `/images/`, `/songs/`, `/fonts/`, and PDF URLs remain valid.

All local page and asset references use root-based URLs such as `/research/` and `/images/...`.
Run `npm run dev` to build both halves, serve them together on port 8080, and rebuild after edits.

The HTML documents depend only on `/native.css`, `/native.js`, and shared media URLs. They do not
load Quartz page styles or its `prescript.js`/`postscript.js` runtime. `npm run create:native-pages`
is the one-time migration helper that regenerates them from the former Markdown sources; normal
content edits should now be made directly in these HTML files.

The original Markdown sources are preserved under
`content/private/standalone-markdown-backup/`. Quartz ignores that folder, while Git keeps the
backup recoverable. Each generated HTML file records the source path and checksum used by the
archive command to prevent moving content that has not first been regenerated and verified.
